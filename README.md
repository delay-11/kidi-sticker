# UV DTF 스티커 시안 제작 사이트 업데이트 기록

UV DTF 스티커 시안 제작 사이트의 주요 수정 및 개선 내역

---

## v1.0.2 여러 개 편집 / 정렬 기능 및 메일 시안 정리

* 인쇄 안전선을 사방 2cm → 0.5cm로 변경 (안전선 라벨은 선 안쪽에 표시)
* 이미지 업로드 시 기본 가로 5cm 대신 이미지 파일의 DPI 정보 기준 실제 크기 그대로 배치 (DPI 정보가 없으면 300dpi 기준)
* 스티커를 여러 개 선택한 뒤 복제하면 서로의 위치를 유지한 묶음으로 복제
* 자동 배치에서 선택한(또는 용지에 있는) 스티커가 2종 이상이면 각자 크기 그대로 번갈아 배치
* 여러 개 선택 시 포토샵식 정렬 아이콘(왼쪽 / 가로 가운데 / 오른쪽 / 위 / 세로 가운데 / 아래 맞춤, 가로 / 세로 간격 균등) 추가
* 업로드 안내 칩을 업로드 버튼 옆으로 옮기고 `PC 환경 사용 권장` 추가, `PNG / JPG / WEBP` 칩 제거
* 메일 본문 시안 미리보기 아래 안내 문구와 용지 / 배치한 스티커 개수 표 제거

---

## v1.0.1 모바일 편집 개선 및 시안 확인 화면 정리

* 모바일에서 도구 탭 → 패널 → 선택한 스티커(가로 / 세로 / 비율) → 용지 / 뒤로가기 / 초기화 순서로 상단에 고정되어 작업 중에도 뒤로가기 / 초기화를 바로 누를 수 있도록 개선
* 모바일에서 이미지 / 스티커 / 텍스트 패널을 접기 / 펼치기 버튼으로 접을 수 있도록 추가 (캔버스를 만지면 자동으로 접히고, 용지 전체가 한 화면에 보이도록 캔버스 위치 / 크기 조정)
* 모바일에서 캔버스 위 스티커 드래그가 안 되거나 화면이 스크롤되지 않던 문제 수정
* 비율 고정을 풀면 캔버스에서 모서리를 끌어 가로 / 세로를 따로 조절할 수 있도록 개선 (마우스 / 터치 모두)
* 자동 배치 기본 여백을 1cm로 변경
* 텍스트 도구 순서를 텍스트 입력 → 새 텍스트 → 글씨 스타일 → 글자 색상으로 정리하고, 글씨 스타일 4종과 글자 색상(9가지)이 한 줄에 보이도록 변경
* 시안 확인 화면에서 모바일은 주문번호 / 용지 / 스티커 수를 미리보기 위에 한 줄로 표시하고, 안내 문구 정리
* 새로고침해도 입력한 주문정보(주문자명 / 핸드폰번호 / 주문번호 / 이메일 / 용지)가 유지되도록 개선

## v1.0 초기 오픈

* UV DTF 스티커 시안 제작을 위한 전용 사이트 개설
* 주문정보 입력 → 용지 선택 → 시안 제작 → 시안 확정 순서의 단계형 제작 흐름 구성
* 용지 사이즈 A3 / A4 / A5 선택 및 사방 2cm 인쇄 안전선 표시
* 이미지 업로드(PNG / JPG / WEBP), 기본 제공 스티커(카테고리별 아이콘), 텍스트(폰트 / 글자 색상 선택) 추가 기능
* 선택한 스티커의 가로 / 세로 크기 조절(비율 고정), 복제, 삭제 기능
* 가로 / 세로 / 여백을 입력하면 안전선 안에 자동으로 배치되는 자동 배치 기능
* 모바일에서 도구 패널이 하단에 고정되고, 이전 / 다음 단계 버튼이 스크롤 시 상단에 고정되도록 구성
* 이메일 입력 시 `@` 뒤 자주 쓰는 도메인 자동완성
* 스티커 전용 시안 접수 메일 템플릿(회사 수신 / 구매자 수신) 적용
* 메일 본문에 시안 확정 화면과 똑같이 배치된 그대로의 시안 미리보기 표시 (투명 영역 체크무늬 + 인쇄 안전선)

## 운영 안내

본 사이트는 UV DTF 스티커 시안 제작 및 접수를 위한 전용 제작 시스템입니다.

구매자는 주문 정보 입력 후 구매한 용지 사이즈를 선택하고, 이미지 업로드 또는 스티커 / 텍스트를 추가해 용지 위에 직접 배치하여 시안을 제작할 수 있습니다.

시안 확정 후에는 제작이 진행될 수 있으므로, 주문 정보와 시안 내용을 반드시 확인한 뒤 확정해야 합니다.
